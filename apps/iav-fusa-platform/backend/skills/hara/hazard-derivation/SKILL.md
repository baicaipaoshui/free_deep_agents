# Stage 3 — `derive_hazards`

## 职责

将 Stage 2 的失效模式与 Stage 1 的工况进行笛卡尔组合，推导出车辆级**危险事件（Hazardous Event）**。
结果填充到 `HARAState.hazards`。

## 推导思路

对每个安全相关失效模式（`safety_relevant=true`）逐一提问：

> "如果 **[失效模式]** 在 **[工况]** 下发生，车辆会出现什么行为？该行为会对人员造成什么伤害？"

仅在失效模式与工况的组合**存在人员伤亡风险**时生成危险事件记录。

## 危险事件命名格式

```
[失效模式描述] × [工况] → [车辆行为变化]
```

**示例：**
- `转向辅助完全失效 × 高速转弯 → 驾驶员转向力过大，转弯不足，车辆驶出车道`
- `意外施加转向力矩 × 直线高速行驶 → 车辆突然偏航，驾驶员失控`

## 工况与暴露概率参考

| 工况 | 代表条件 | E 参考值 |
|------|---------|---------|
| 高速行驶 | >100 km/h，高速公路 | E3（0.1%~10%）|
| 城市行驶 | 30~60 km/h，城市道路 | E4（>10%）|
| 弯道行驶 | 转向角 >15° | E3 |
| 低速泊车 | <10 km/h | E4 |
| 紧急制动 | ABS 介入 | E2（0.01%~0.1%）|
| 湿滑路面 | 雨天/冰雪，低附着系数 | E2 |
| 坡道行驶 | 坡度 >8% | E2 |

## 排除标准（标注 QM，不生成危险事件）

满足以下任一条件的失效模式 × 工况组合可排除：
- 仅导致驾驶不适，不影响车辆方向/制动控制
- 仅造成噪音、振动
- 仅导致纯财产损失，无人员伤亡风险

## 每条记录格式

```json
{
  "id": "H-001",
  "failure_mode_id": "FM-001",
  "operational_situation": "高速行驶（>100km/h）",
  "hazardous_event": "转向辅助完全失效 × 高速转弯 → 驾驶员转向力过大，转弯不足，车辆驶出车道",
  "safety_relevant": true,
  "preliminary_exposure": "E3"
}
```

## 输出汇总表

| 危害 ID | 失效模式 ID | 工况 | 危险事件描述 | 安全相关 | 初步 E |
|--------|-----------|------|------------|---------|--------|
| H-001 | FM-001 | 高速行驶 | 转向辅助失效→高速转弯不足 | 是 | E3 |
| H-002 | FM-003 | 直线行驶 | 意外施加反向力矩→车辆偏航 | 是 | E4 |

## 完成标志

回复中标注 `[HARA Stage 3 完成]`，输出危险事件 JSON 列表及汇总表。
