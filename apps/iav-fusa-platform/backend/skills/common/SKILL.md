# 功能安全通用技能

## 触发条件
始终激活。提供 ISO 26262 通用背景知识。

## ISO 26262 标准结构
- Part 3: 概念阶段（HARA、安全目标）
- Part 4: 系统级产品开发
- Part 5: 硬件级产品开发
- Part 6: 软件级产品开发
- Part 9: ASIL 分解与安全分析方法

## ASIL 等级
QM（无特殊要求）< ASIL-A < ASIL-B < ASIL-C < ASIL-D（最高）

## 关键原则
- 所有分析必须严格遵循 ISO 26262:2018
- HARA → FMEA → FTA 形成完整的安全分析闭环
- 安全目标必须可验证、无歧义、与技术实现无关
